# Формат образа AxOS

## Обзор

Образ AxOS (`build/os-image.bin`) — это raw-образ дискеты 1.44 МБ
(`1 474 560` байт) без файловой системы на верхнем уровне. Он содержит
загрузчик, ядро и встроенный FAT12 RAM-диск, объединённые в один бинарный
файл фиксированного размера. Образ собирается автоматически скриптом
`build.bat`.

## Структура образа

```text
┌─────────────────────────────────────────────────────────────┐
│ Байты 0 – 511:        boot.bin (boot.asm)                     │
│ Размер:               512 байт (1 сектор)                     │
│ Описание:             MBR/загрузочный сектор: переключает CPU │
│                       в защищённый режим и грузит kernel.bin  │
├─────────────────────────────────────────────────────────────┤
│ Байты 512 – ...:      kernel.bin                              │
│ Размер:               до 17920 байт (35 секторов)             │
│ Описание:             Ядро AxOS в защищённом режиме           │
│                       (.text/.data/.bss, грузится в 0x1000)   │
├─────────────────────────────────────────────────────────────┤
│ Байты ... – 18431:    Padding (нули)                          │
├─────────────────────────────────────────────────────────────┤
│ Байты 18432 – 83967:  fat12.bin (FAT12 RAM-disk)              │
│ Размер:               65536 байт (64 КБ, 128 секторов)        │
│ Описание:             Содержимое каталога fs/, упакованное    │
│                       tools/make_fat12.py; грузится в 0x20000 │
├─────────────────────────────────────────────────────────────┤
│ Байты 83968 – 1474559: Padding (нули)                         │
│ Описание:             Заполнение нулями до размера дискеты    │
└─────────────────────────────────────────────────────────────┘
```

## Точные смещения

### boot.bin

- **Начало**: байт 0 (сектор 0)
- **Размер**: 512 байт
- **Источник**: `nasm -f bin src/boot/boot.asm -o build/boot.bin`
- **Роль**: загрузочный сектор (сигнатура `0x55AA` в конце), читает
  `kernel.bin` (35 секторов) в `0x1000` и FAT12-раздел (128 секторов) в
  `0x20000`, переключается в защищённый режим (`switch_to_pm.asm`,
  `gdt.asm`) и передаёт управление по адресу `0x1000`.

### kernel.bin

- **Начало**: байт 512 (сразу после `boot.bin`)
- **Размер**: переменный, должен не превышать `17920` байт (35 секторов ×
  512), иначе `boot.asm` не загрузит ядро целиком
- **Источник**: линковка объектных файлов ядра (`kernel_entry.o`, `idt.o`,
  `kernel.o`, `screen.o`, `fat12.o`, `paging.o`, `tss.o`, `heap.o`,
  `syscalls.o`, `usermode.o`) через `kernel.ld` (`ENTRY(_start)`, секции с
  адреса `0x1000`) и `objcopy -O binary`
- **Роль**: ядро AxOS — обработка прерываний, paging, TSS/ring3, куча, FAT12,
  shell

### Padding до FAT12-раздела

- **Начало**: сразу после `kernel.bin`
- **Конец**: байт `18431` (сектор 36 начинается с байта `18432`)
- **Содержимое**: нули

### fat12.bin (встроенный FAT12 RAM-диск)

- **Начало**: байт `18432` (сектор 36)
- **Размер**: `65536` байт (64 КБ, 128 секторов)
- **Источник**: `tools/make_fat12.py`, упаковывает файлы из `fs/`
  (`MOTD.TXT`, `STARTUP.CFG`) в минимальный FAT12-том (1 FAT, 16 корневых
  записей, 1 сектор/кластер)
- **Роль**: `boot.asm` читает этот раздел в RAM по адресу `0x20000`, ядро
  читает его оттуда через `src/fs/fat12.c` (команды `ls`/`cat`, только
  чтение)

### Финальный padding

- **Начало**: сразу после `fat12.bin` (байт `83968`)
- **Конец**: байт `1 474 559` (1.44 МБ)
- **Содержимое**: нули — образ дополняется до размера стандартной дискеты,
  чтобы QEMU/реальный контроллер дискет распознал его как floppy

## Процесс создания образа

Образ собирается шагами `build.bat` (см. также корневой `README.md`):

```text
1. nasm -f bin src/boot/boot.asm -o build/boot.bin
2. Компиляция и линковка ядра -> build/kernel.bin (через kernel.ld)
3. python tools/make_fat12.py -> build/fat12.bin (из содержимого fs/)
4. copy /b build/boot.bin + build/kernel.bin -> build/os-image.bin
5. Дополнение build/os-image.bin нулями до 1 474 560 байт
6. Запись build/fat12.bin в build/os-image.bin по смещению 18432
```

## Ограничения

- **Максимальный размер `kernel.bin`**: 17920 байт (35 секторов) — задаётся
  таблицей чтения диска в `boot.asm`. Если ядро не уместится, его нужно либо
  уменьшить, либо увеличить число читаемых секторов в `boot.asm` и сдвинуть
  смещение FAT12-раздела соответственно.
- **Размер FAT12-раздела**: фиксирован — 64 КБ (128 секторов), смещение
  `0x20000` в RAM захардкожено и в `boot.asm`, и в `fat12.c`.
- **Файловая система верхнего уровня**: отсутствует — `os-image.bin` это
  raw-образ дискеты, читаемый только через геометрию CHS, которую понимает
  `boot.asm`.
- **Архитектура**: x86, 32-битный защищённый режим.
- **Порядок компонентов**: жёстко зафиксирован (см. таблицу смещений выше).

## Совместимость

Образ совместим с:

- QEMU (`qemu-system-i386 -drive format=raw,file=build/os-image.bin,if=floppy -boot a`)
- Реальной дискетой 1.44 МБ или образом для USB-эмулятора floppy

## Запуск в QEMU

```bash
# Базовый запуск (как в run.bat)
qemu-system-i386 -drive format=raw,file=build/os-image.bin,if=floppy -boot a

# С логом прерываний для отладки
qemu-system-i386 -drive format=raw,file=build/os-image.bin,if=floppy -boot a -d int
```

## Изменение формата

Если вы хотите изменить формат образа:

1. Обновите `build.bat` (шаги сборки/склейки/паддинга/встраивания FAT12).
2. Если меняется смещение или размер FAT12-раздела — обновите константы в
   `tools/make_fat12.py`, таблицу чтения диска `load_fat12`/`fat12_table` в
   `src/boot/boot.asm` и адрес `0x20000` в `src/fs/fat12.c`.
3. Если меняется лимит размера `kernel.bin` — обновите таблицы чтения секторов
   в `boot.asm` (`fat12_table` начинается сразу после ядра).
4. Обновите эту документацию и карту памяти в `README.md`.
5. Протестируйте сборку (`build.bat`) и загрузку в QEMU (`run.bat`) перед
   использованием на реальном железе.

## История

Ранние версии проекта использовали другой формат — 10 МБ raw-образ
`Unknown/axos_system.img`, собираемый Node.js-скриптом
`Unknown/packager.js` без встроенной файловой системы. Этот формат больше не
используется текущей сборкой (`build.bat`); файлы в `Unknown/` сохранены как
исторический артефакт.
